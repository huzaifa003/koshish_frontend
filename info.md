# Project structure

Next.js App Router, React, TypeScript, Tailwind CSS 3, and shadcn/ui.

- `src/app/`: routes, shared layout, and the inquiry API.
- `src/views/`: public home, contribution flow, and internal workspace.
- `src/components/`: shared shadcn controls and page components.
- `src/lib/`: Supabase client, portal state, form validation, and formatting.
- `supabase/`: hosted database setup, upgrade migration, and optional sample seed.
- `tests/`: local PostgreSQL privacy and form validation checks.

See README.md for environment variables, hosted Supabase setup, and deployment.
